# testtesting
Создайте метод с именем analyzeText, который принимает String (text) и выполняет расширенный анализ сопоставления шаблонов. Метод должен:1.Подсчитывать и категоризировать все слова в:Простые слова (только буквы)Числа (целые и десятичные)Адреса электронной почты (содержат @ и домен)URL (начинаются с http:// или https://)2.Для каждой категории возвращать:Количество совпаденийПозицию первого вхожденияФактическое содержимое совпадения (до 3 элементов)Формат возвращаемого значения должен быть:Кроме того, создайте метод validateMatches, который принимает String (text) и возвращает true, если:Все адреса электронной почты заканчиваются на .com, .org или .netВсе URL безопасны (https://)Все числа положительныеВсе слова имеют длину не менее 3 символовСообщения для возврата должны быть:If text is null: return "Invalid input"If text is empty: return "Empty text"If no matches found: return "No matches found"
